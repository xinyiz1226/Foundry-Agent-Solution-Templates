# Information extraction

This project was built with the microsoft-foundry skill. Before working on or answering questions about foundry agents, read the microsoft-foundry skill first.

For scope and outstanding gates, read `docs/implementation-plan.md`. Keep the
deployed synthetic G0 entry points separate from the configurable local workbench.
Preserve immutable plans, requests, source evidence and execution history.

For local uploads or profile execution, read `docs/configured-workbench.md`.
For cloud operations, read `docs/guarded-deployment.md` before changing resources;
local source changes are not evidence of a new deployment.
